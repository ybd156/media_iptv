客户端更新

上传新的 APK，客户端启动时会自动检查并提示升级（设置页也能手动检查）。 版本号由服务端从 APK 里直接读取，不需要手填 —— 手填错了会导致客户端永远提示有新版。 只保留最近 2 个版本，更早的会自动删除。
注意：安装包必须是用同一套密钥签名的 release 包，否则客户端无法覆盖安装。

系统设置

客户端播放配置

客户端取值顺序：客户端设置页里用户改过的 > 这里下发的 > 客户端内置默认。 也就是说用户自己动过的那一项，这里改不动它。 改动由客户端心跳取走，最长 60 秒后生效，且引擎/偏移变化时会重连当前频道。
客户端默认用哪个内核（ijk 内置 AV3A 解码器）
客户端播放缓冲。客户端设置页里缓冲只有低/中/高三档，用户选过档位就以客户端的为准
贴直播边缘播放的目标偏移；越大越稳但画面越滞后
客户端画面比例默认值
客户端暂未实现这一项：目前总是自动播放上次观看的频道，所以这里置灰
